1. SPECTRAL EXTRACTION SPECIFICATIONS & METHODOLOGY
--------------------------------------------------------------------------------
* Method: Welch's Power Spectral Density (scipy.signal.welch)
* Sampling Frequency (fs): 128 Hz
* Window Size (nperseg): 256 samples (2.0 seconds)
* Window Function: Hann window
* Frequency Resolution (df): 0.50 Hz
* Numerical Integration: Composite Trapezoidal Rule (scipy.integrate.trapezoid)
* Frequency Band Definitions:
    - Delta:  0.5 - 4.0 Hz
    - Theta:  4.0 - 8.0 Hz
    - Alpha:  8.0 - 13.0 Hz
    - Beta:  13.0 - 30.0 Hz
    - Total:  0.5 - 30.0 Hz (consistent with preprocessed filter passband)
* Features Extracted Per Channel (19 channels):
    1. Absolute Powers: [band]_abs for delta, theta, alpha, beta, total (5 features)
    2. Relative Powers: [band]_rel = [band]_abs / total_abs for delta, theta, alpha, beta (4 features)
    3. Clinical Ratio:  tbr = theta_abs / beta_abs (1 feature)
    Total Per Channel: 10 features x 19 channels = 190 features per epoch.
