🎯 Research Questions

1. Channel Reduction (RQ 1): Can machine learning classifiers accurately categorize pediatric ADHD using a predefined, smaller electrode set (e.g., 4–5 frontal/central sites) compared to the standard full 19-channel cap?

2. Noise Robustness (RQ 2): How does signal degradation (controlled simulated noise across SNR levels: +20 dB to -5 dB) affect classifier accuracy across full versus reduced channel montages?

🔬 Scientific Pipeline Architecture

  1. Continuous Zero-Phase Filtering: 0.5–30 Hz Butterworth bandpass + 50 Hz notch.
  2. Artifact-Free Epoching: 2.0s non-overlapping windows (256 samples).
  3. Spectral Feature Extraction: Welch PSD per channel for Delta, Theta, Alpha, Beta, & TBR.
  4. Subject-Independent Split: All epochs of any child remain strictly in one fold.
  5. Pipeline Isolation: Scalers fitted strictly on training fold data.

Research Question 2 Answer: Both full and reduced montages demonstrate strong resilience against moderate noise (retaining >93% accuracy at +10 dB). Under heavy noise (+5 dB), the full 19-channel cap maintains higher headroom due to multi-channel spatial averaging.

🔍 Key Noise Observations

  • +20 dB & +10 dB: Performance remains virtually intact (100% to 96% retention), demonstrating that spectral features are stable against moderate ambient noise.
  • +5 dB Threshold: Single-channel and 2-channel features suffer higher relative disruption than the 19-channel array, which benefits from spatial redundancy.
  • 0 dB to -5 dB Breakdown: When noise power equals or exceeds EEG microvolt amplitude, classifiers converge to chance level (50%).

🛡️ Scientific Simulation Boundary

In accordance with project guidelines, all noise testing was conducted by adding Gaussian noise strictly to test partition copies with fixed random seeds. Raw original signals were kept pristine. These results quantify algorithmic signal degradation tolerance and are explicitly noted as simulations.
